# BancoDevMat

Projeto de um sistema bancário desenvolvido em Java, com o objetivo de praticar programação e desenvolver habilidades na construção de aplicações.

## 📌 Sobre o projeto

O **BancoDevMat** é um projeto pessoal voltado ao aprendizado de programação, utilizando Java para desenvolver um sistema relacionado a operações bancárias.

## 🎯 Objetivos

- Praticar os fundamentos da linguagem Java.
- Desenvolver o raciocínio lógico.
- Aplicar os conhecimentos adquiridos em um projeto prático.
- Evoluir minhas habilidades em desenvolvimento de software.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/Mateusrosk/BancoDevMat.git
   ```

2. Abra o projeto em uma IDE compatível com Java, como o IntelliJ IDEA.
3. Localize a classe principal do programa.
4. Execute o método `main`.
